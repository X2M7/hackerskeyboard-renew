Hackers Keyboard Renew

A modernized fork of Hacker's Keyboard for Android, optimized for terminal users, developers, SSH workflows, and physical keyboard-style input.

GitHub Repository Privacy Policy

Modern Android Support

Updated for recent Android versions with improved compatibility for modern devices.

Developer Friendly

Full PC-style layout including Ctrl, Alt, Esc, arrow keys, and function keys.

Privacy Focused

No telemetry, no analytics, no ads, and no cloud tracking.

Features

  • 5-row keyboard layout
  • Terminal and SSH optimized
  • Works well with Termux
  • Landscape and fullscreen support
  • Arrow keys and modifier keys
  • Open source under Apache 2.0
  • Lightweight and minimal

Open Source

This project is based on the original Hacker's Keyboard project by Klaus Weidner and continues its mission with modern Android support and usability improvements.
